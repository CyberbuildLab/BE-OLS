# Contributing to the Built Environment Ontology Lookup Service (BE-OLS)

Thank you for your interest in contributing to the BE-OLS.

BE-OLS is a community-oriented resource for discovering, exploring, analysing and comparing ontologies relevant to the built environment. Contributions that improve the ontology collection, metadata quality, functionality, usability, documentation and evalaution are welcome.

## 1. Submitting a new ontology

To propose an ontology for adding to the database:

1. Open the repository’s [**Issues page**](https://github.com/CyberbuildLab/BE-OLS/issues) page.
2. Select **New issue**.
3. Choose [**New Ontology Submission**](https://github.com/CyberbuildLab/BE-OLS/issues/new?template=new-ontology-submission.yml).
4. Complete all requested fields.
5. Submit the issue for review.

Submitting an issue does not directly add the ontology to BE-OLS. The submission will first be reviewed for relevance, accessibility, completeness and possible duplication.
Before submitting, please check whether the ontology is already available in BE-OLS or has previously been proposed.

## 2. Reporting incorrect or missing information

Open an issue for:

- incorrect or missing ontology information
- broken links
- bugs
- visualisation or usability problems

Include clear details, relevant links, and screenshots where useful.

## 3. Propose a feature

Open an issue before developing a substantial new feature. Please submit separate issues and pull requests for independent features so they can be reviewed individually.
